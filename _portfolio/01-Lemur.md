As part of my Major Qualifying Project (MQP) at Worcester Polytechnic Institute, I designed and developed a complete educational curriculum focused on applying machine learning to robotics. The project addressed a gap in the undergraduate robotics curriculum by creating hands-on modules that teach students how to deploy machine learning models on real robotic systems.

The final product consisted of course materials, laboratory exercises, workshop content, and supporting software that can be integrated into existing robotics courses or used as the foundation for a dedicated machine learning for robotics course.

## Problem

While machine learning has become increasingly important in robotics, undergraduate students often learn the underlying theory without gaining practical experience applying these techniques to real robotic systems. Existing coursework provided theoretical foundations but offered limited exposure to:

- Deploying machine learning models on embedded hardware
- Optimizing models for resource-constrained systems
- Applying reinforcement learning to robotics problems
- Integrating machine learning into robotic decision-making pipelines

Our goal was to bridge this gap through a hands-on, application-focused curriculum.

## Methodology

### Curriculum Development

Designed and developed educational modules covering:

- PyTorch fundamentals
- Transfer learning
- Model optimization techniques
- Reinforcement learning & Computer Vision
- Embedded machine learning deployment

### Hardware Integration

Built and tested machine learning workflows using:

- Raspberry Pi embedded computers
- Pololu Romi robots
- Camera-based computer vision systems
- GPU-accelerated training environments, both cloud and students laptops if they had an integrated GPU

### Machine Learning Applications

Implemented and taught:

- Transfer learning for image classification
- Model quantization
- Model pruning
- Reinforcement learning using Q-learning
- Sim-to-real robotics workflows

### Educational Assessment

Designed and conducted student workshops to evaluate:

- Student confidence before and after instruction
- Understanding of machine learning concepts
- Effectiveness of hands-on learning activities
- Interest in machine learning for robotics applications

## Results

The completed curriculum consisted of multiple educational modules that guided students from introductory machine learning concepts through advanced robotics applications. Workshop participants demonstrated improved confidence in explaining and understanding machine learning concepts, particularly in:

- Transfer learning
- Model optimization
- Reinforcement learning

The project produced a reusable set of educational materials that can be incorporated into undergraduate robotics education and serve as a foundation for future coursework in machine learning for robotics.
